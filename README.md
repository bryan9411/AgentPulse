# AgentPulse

在同一個終端機視窗裡，輕鬆管理多個 AI coding agent（AI 寫程式助理）。

左邊清楚列出每個專案中所有 AI 的即時狀態；右邊直接嵌入目前選取的 AI 終端機畫面，按一下就能切過去交談。關掉視窗後 AI 依然會在背景持續執行，下次打開無縫接軌。

目前支援 Claude Code（`claude`）、Antigravity CLI（`agy`）與 Codex CLI（`codex`）。

---

## 安裝前準備

在 macOS 的「終端機」執行以下檢查與安裝：

### 1. 安裝 tmux（必備）
AgentPulse 利用 tmux 在背景維持 AI 的運作。需要 3.2 以上版本：
```bash
brew install tmux
```
*(如果電腦尚未安裝 Homebrew 套件管理工具，請參考 [brew.sh](https://brew.sh) 先行安裝)*

### 2. 安裝 Apple 開發者工具（包含 git）
```bash
xcode-select --install
```
*(若畫面顯示已安裝「already installed」，直接略過即可)*

### 3. 安裝並登入至少一家 AI 工具
請確認電腦已裝好你想用的 AI CLI（例如 Claude Code 或 Antigravity CLI），並先在終端機中手動執行過一次完成登入授權。

### 4. 安裝 delta（建議安裝，美化程式碼 Diff 檢視）
按 `d` 檢視程式碼修改時，若系統有安裝 `delta`（套件名稱為 `git-delta`），會自動啟用**語法高光配色、行號、詞級差異**以及 **`s` 並排對比檢視**：
```bash
brew install git-delta
```
*(若暫時不安裝也能正常使用，會自動改以內建的彩色行號 Diff 畫面呈現；安裝後隨時按 `d` 就會立即套用)*

## 快速安裝與啟動

### 1. 安裝步驟

專案內建自動化安裝腳本，就算電腦**沒有安裝 Bun 也能使用**（腳本會自動暫時下載 Bun 來編譯，安裝完成後自動清理暫存，完全不佔用空間）：

1. 打開終端機，切換到本專案資料夾：
   ```bash
   cd AgentPulse
   ```
2. 執行安裝腳本：
   ```bash
   ./install.sh
   ```
3. 安裝完成後，系統「應用程式」資料夾會出現 **AgentPulse.app**。

### 2. 啟動方式

- **從應用程式或 Spotlight 啟動：**
  - 按下鍵盤 `Cmd + 空白鍵` 喚出 Spotlight，輸入 `AgentPulse` 按 Enter。
  - 或直接打開 Finder 進入「應用程式」，雙擊 `AgentPulse` 圖示。
  - *系統會優先使用 iTerm2 開啟，若未安裝則使用 macOS 內建的「終端機」開啟。*
- **從終端機直接啟動：**
  - 進到你的專案資料夾後直接執行 `agentpulse`，該專案目錄會自動加入管理清單。

> **背景運作提醒**：
> 關閉終端機視窗並**不會**中斷 AI 的工作。下次重新打開 AgentPulse，所有的對話進度與 AI 狀態都會完整保留。

## 操作步驟

第一次開啟 AgentPulse 時，左邊的清單是空的，依照以下步驟即可開始：

1. **加入專案**：按鍵盤 `a`，輸入你電腦中某個專案資料夾的完整路徑（必須是 git 儲存庫）。
2. **新增 AI**：將反白光棒移到專案上，按 `n`，選擇你想啟動的 AI 助理（例如 Claude Code）。
   *(若想在獨立的 Git worktree 分支中執行，可改按 `w`)*
3. **開始對話**：選中該 AI 後按 `enter`，焦點會切換到右側畫面，直接開始打字與 AI 交談。
4. **切換回清單**：交談時隨時按 `ctrl+q`，即可把游標切回左側清單選擇其他 AI。
5. **離開程式**：回到左側清單後按 `q` 退出。背景中的 AI 依然會繼續跑。

## 多分支平行開發與 Worktree 工作區

當你想讓同一個專案**同時在多條分支上各自跑 AI**（例如一條開在 `dev`、同時另一條開 `main` 或新功能分支 `feat/login`）而不會互相覆蓋檔案，可以搭配 `w` 建立獨立工作區（Git worktree）：

1. **在主資料夾目前分支開 AI（按 `n`）**
   專案原本的資料夾停在哪個分支（例如 `dev`），按 `n` 就會直接在該資料夾啟動 AI。
2. **同時開其他分支平行工作（按 `w`）**
   在專案上按 **`w`**，可以選擇要開啟的分支：
   - **開啟既有分支**：直接挑本機尚未被其他資料夾開啟的分支（例如專案停在 `dev` 時，直接選 `main` 或其他功能分支）。
   - **建立新分支**：直接輸入新名稱（例如 `feat/login`），從目前分支分出新分支。
   系統會在專案旁建立 `<專案名>.worktrees/<分支名>` 資料夾並啟動 AI；若多個工作區同時改到同一個檔案，清單下方會顯示衝突預警。
3. **檢視修改內容（按 `d`）**
   選中任一 AI 按 **`d`**，以滿版 Diff 視窗逐檔檢查它的改動（支援滑鼠滾輪與 `←` / `→` 切換檔案）。
4. **關閉 AI 與清理資料夾（按 `x`）**
   選中 AI 按 **`x`** 可停止該 AI；如果是某個 worktree 資料夾裡最後一個 AI，畫面還會讓你選擇「**只關閉 AI（保留資料夾）**」或「**同時移除 worktree 資料夾**」（不會刪除 Git 分支本身；若資料夾內還有未提交修改會自動保留不強刪）。

> **Git 限制小提醒**：同一條 Git 分支同時只能被一個資料夾開啟，因此主資料夾正在使用的分支（例如 `dev`）請用 **`n`** 新增 AI，其餘分支可用 **`w`** 各自開獨立資料夾並存。

## 常用快捷鍵操作

在 AgentPulse 裡隨時按下 **`?`** 即可叫出按鍵說明選單。

### 🔹 在右邊跟 AI 對話時

| 按鍵 | 作用 |
|---|---|
| **`ctrl+q`** | **回到左側清單**（若先前有放大畫面也會一併還原） |
| **其他所有按鍵** | **一律直接送給 AI**（包含 `ctrl+c`，代表中斷 AI 當前的回答） |

### 🔹 在左側清單時

| 按鍵 | 作用 |
|---|---|
| `↑` `↓` 或 `k` `j` | 上下移動選取項目，右邊會即時預覽該 AI 的畫面 |
| `←` `→` 或 `h` `l` | 收合或展開專案分組 |
| `enter` | 進入右側開始與該 AI 對話 |
| `z` | 進入對話，同時將畫面**全螢幕放大** |
| `n` | 在目前專案新增一個 AI 助理 |
| `w` | 挑選既有分支或建立新分支（獨立 Git worktree 資料夾）並啟動 AI |
| `x` | 關閉選中的 AI（獨立 worktree 可選一併移除乾淨資料夾；選中專案則為移除專案） |
| `d` | 以滿版視窗查看該 AI 所在目錄的程式碼修改（`←` / `→` 切換檔案、`↑` `↓` / `Space` / 滑鼠滾輪捲動、`s` 切換並排、`q` / `esc` 關閉） |
| `o` | 用瀏覽器開啟該專案的本機網頁伺服器（`http://localhost:<port>`） |
| `/` | 搜尋清單中的專案或 AI（按 `esc` 清除搜尋） |
| `f` | 篩選模式：只列出正在等待你處理的 AI |
| `a` | 手動加入專案資料夾 |
| `t` | 切換介面語言（繁體中文 / 英文） |
| `?` | 以滿版視窗顯示完整按鍵說明（支援滑鼠滾輪與鍵盤捲動） |
| `q` | 離開 AgentPulse（所有 AI 會在背景繼續運作） |

## 狀態符號說明

清單中每個 AI 名稱前方都會有狀態圖示，方便你一眼掌握進度：

| 圖示 | 狀態意義 |
|:---:|---|
| `●` | **工作中**：AI 正在思考、撰寫程式碼或呼叫工具 |
| `◐` | **等待確認**：AI 正在等待你核准執行指令或回答問題 |
| `○` | **等待輸入**：AI 目前閒置，等待你給予下一個任務 |
| `✓` | **已完成**：任務已完成，你尚未切過去檢視 |
| `✕` | **出錯停下**：執行過程中發生錯誤中斷 |

## 設定檔說明

設定檔路徑：`~/.config/agentpulse/config.json`
首次啟動時會自動建立，可直接用文字編輯器開啟修改：

| 欄位 | 說明 | 預設值 |
|---|---|:---:|
| `projects` | 已加入清單的專案資料夾路徑列表 | `[]` |
| `sidebarWidth` | 左側清單欄位寬度（字元數） | `36` |
| `notifications` | 當 AI 等待你同意或出錯時，是否發送 macOS 系統通知 | `true` |
| `glyphs` | 符號顯示相容性，若圖示排版對不齊可改為 `"ascii"` | `"unicode"` |
| `keys.back` | 從對話切回清單的快速鍵（tmux 格式，`C-q` 代表 `ctrl+q`） | `"C-q"` |
| `contextWarnAt` | Token 記憶體用量達百分之幾時變色提醒 | `80` |
| `language` | 介面語系：`"zh-TW"`（繁體中文）或 `"en"`（英文） | `"en"` |

> 系統執行記錄檔存放在同目錄下的 `agentpulse.log`。

## 如何解除安裝（完整移除）

如果你不再需要使用 AgentPulse，專案內附有乾淨的移除腳本：

1. 打開終端機，執行專案內的移除腳本：
   ```bash
   ./uninstall.sh
   ```
2. 腳本會提示將執行的清除動作（會列出背景執行的 AI、應用程式檔案、設定檔路徑等）。
3. 輸入 `y` 並按下 Enter，即可將 AgentPulse 從你的 Mac 完整清除，不留任何殘留設定或背景行程。

## 常見問題（FAQ）

**Q：怎麼完全離開程式？按 `ctrl+c` 好像沒用？**  
A：當焦點在右邊對話區時，`ctrl+c` 會直接交給 AI（用於中斷 AI 輸出）。若要離開，請先按 **`ctrl+q`** 切回左側清單，再按 **`q`** 即可安全退出。所有背景中的 AI 不會受到影響。

**Q：按了 `ctrl+c` 之後 AI 畫面顯示 exited？**  
A：這代表該 AI 程序的行程已被手動中止。請按 `ctrl+q` 回到左側清單，按 `x` 移除該項目，再按 `n` 重新開啟一個新的 AI。

**Q：第一次啟動時畫面卡住沒有反應？**  
A：若你的專案放在「文件」、「桌面」或「下載項目」資料夾，macOS 首次執行時會彈出隱私權限提示，詢問是否允許終端機存取檔案，點擊「允許」後即可正常運作。

**Q：按 `shift+enter` 為什麼沒有換行，而是直接送出了？**  
A：macOS 內建的「終端機」預設無法區分 `shift+enter`。建議換行時改按 **`ctrl+j`**，或者改用 iTerm2 終端機軟體即可支援 `shift+enter` 換行。

**Q：狀態圖示好像佔了兩格寬、版面排不齊？**  
A：可開啟設定檔將 `glyphs` 改成 `"ascii"`。若使用 iTerm2，請檢查 Settings → Profiles → Text 的「Treat ambiguous-width characters as double width」選項是否被勾選（建議取消勾選）。

**Q：畫面顯示「視窗太小」？**  
A：終端機視窗尺寸至少需要 **70 欄寬、16 行高**，只需手動將視窗拉大一些即可正常顯示。

**Q：更新或修改 AgentPulse 之後畫面怪怪的？**  
A：在終端機執行 `AgentPulse --restart-ui`，即可單獨重啟介面畫面，背景正在運行的 AI 與對話進度都不會受影響。

**Q：這會動到我平常用於其他工作的 tmux 設定嗎？**  
A：完全不會。AgentPulse 採用專屬的兩個 socket 服務（`agentpulse-ui` 與 `agentpulse`），不會讀寫你的 `~/.tmux.conf`，也不會干擾你在本機運行的任何 tmux 工作階段。

## 開發者除錯模式

若要修改原始碼並直接測試功能：

```bash

```

## 自行編譯純二進位執行檔

如果習慣使用 Bun 工具鏈自行編譯單一執行檔：

```bash
bun install
bun run build:mac
```

編譯完成後會在 `dist/` 資料夾產出 `AgentPulse` 單一執行檔。
